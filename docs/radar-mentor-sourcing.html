Define

Three frictions, and the design move that kills each
1 · Salary exposure (A, C) — biggest reason they ghost.
Move: Decouple identity from salary (two separate consent toggles). Ask bands by stage, not exact figures — higher response, still honest, fits salaryProgression shape better anyway.
2 · No payoff (B) — content extraction with nothing back.
Move: Give before you take. Show their own card preview + field reflection stats ("412 students explored this field this month"). Byline + booking_url + LinkedIn in the card.
3 · Impostor gate (D) — "am I qualified?"
Move: Impostor-proof copy: "We want the real messy path, not a highlight reel." Flips the fear into the value prop.
Consent axis 1 — Identity
Anonymous (role only) ▸ First name + role ▸ Full name + photo + links.
Consent axis 2 — Salary
Skip ▸ Band by stage (entry/mid/senior) ▸ Exact, attributed. Never auto-pair full name + exact salary.

Reach

Four channels, run in trust order
Existing expert funnel — warm, lowest friction. Approved experts whose field_category maps to a Radar slug route straight in. Zero new outreach.
Warm network / alumni — highest trust. Hand-pick for reference fields first. Best quotes → the hero card. Personas A & D live here.
Cold LinkedIn / X — scale to fill gaps. Sharp hook + tiny ask. Target 4–10 yrs in. Expect ~10–20% reply.
Cited public threads — gap filler, no outreach. Blind/Reddit/X with publisher+url. Never the hero card; never reconstruct an unstated salary.

Coverage rule: a field ships enriched only when ≥1 interviewed person (T1–3) exists. Each field needs 2–3 people across levels so growth shows. Tier 4 supplements, never carries.

Plumbing

Expert answer → live Radar card
  1. Map expert_profiles.field_category → radar_fields.slug. One-time, editable.
  2. Promote step (admin): approved expert → transform interview_data into a realPeople object → append to radar_cards.content jsonb. Human-in-loop, not auto.
  3. Source row: every promoted person writes a radar_sources row (URL) → citation stays honest.
  4. Renderer check: confirm RadarCards.tsx renders full enriched shape (path, nowDoing, whereHeading, advice) bilingually; patch gaps. blocker
  5. Gap dashboard (optional): per field, real-people count by tier; flag fields under the coverage rule.

No migration needed — radar_cards.content is jsonb. Steps 1–4 = MVP.
